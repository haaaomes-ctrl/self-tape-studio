# Dance rubric research — discipline overview

> **Discipline thread overview** (part of [[drr-programme-overview]]). 13-step builds-on chain, originals dated **4–6 May 2026**, imported 2026-06-08. The **full consolidated Dance rubric** is the archived *Merged* file `knowledge/90-archive/discipline-rubric-research/2.Dance/Dance Rubric Research Merged.md` (not embedded here, by design).

## Arc

Dance was the **second** discipline and ran the full pipeline — a ~72-source census across four batches → synthesis → gap audit → revision → final audit → output-specificity + non-regression mapping → lessons → pre-production synthetic QA → standardised handoff. The problem it solved was not inventing scoring theory but making the existing shared six-field, type-weighted evaluator **truthful for movement**: Dance had the weakest prior credibility because it had no true movement rubric and proxy-mapped onto the overloaded `vocal` field, so the work tightened semantics, evidence anchors, claim-scope and output rules rather than changing schema.

## What the consolidated rubric covers

- Movement technique, **style-anchored**: placement, line, coordination, control, timing, footwork, weight/flow — named per style (ballet / contemporary / jazz-theatre / tap / commercial / street-hip-hop / MT dance) with a mixed/uncertain fallback.
- Musicality / rhythm / dynamics / phrasing, explicitly separated from audio-readability (poor sound must not become poor musicality; tap requires audible footwork).
- Movement-based performance / expression / communication — never spoken-acting language unless acting is genuinely present.
- Assessability as a first-order precondition (full-body framing, stable camera, audible music); weak assessability caps confidence rather than triggering invented criticism.
- Tape-observable vs live-room-only boundary: choreography pick-up, response to direction, adaptability and stamina ring-fenced as low-confidence / live-room-only.
- Accessibility-safe adaptation (no deficit framing) and an explicit forbidden-claim set (body/physique, marketability, bookability, polish-as-talent).

## Deviations / findings

- The core finding is the architectural **`vocal`-field overload** (singing/speech/dance-technique collapsed into one stored field), mitigated only at the wording level and carried as a permanent limitation.
- The whole output-spec/QA stage was **synthetic/adversarial only** — no live Dance report, PDF, JSON or comparison page ever existed (uploaded examples were MT acting+song reports), so renderer/display behaviour (label containment, comparison-page parity, timestamp rendering) stayed unverified.
- Dance subtype handling stays informal (no formal subtype rubrics in code). The Musical Theatre acting+song flow was the protected non-regression anchor throughout.

## Key lesson

A rubric is not done when the wording is improved — only when wording is converted into observable, testable output behaviour and non-regression tests; and each discipline should start by auditing overloaded stored fields and naming a protected anchor before any deep research.
