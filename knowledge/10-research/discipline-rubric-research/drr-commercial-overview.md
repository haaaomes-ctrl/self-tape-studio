# Commercial rubric research — discipline overview

> **Discipline thread overview** (part of [[drr-programme-overview]]). 12-step builds-on chain, originals dated **5–6 May 2026**, imported 2026-06-08. The **full consolidated Commercial rubric** is the archived *Merged* file `knowledge/90-archive/discipline-rubric-research/5. Commercial/C Rubric Research Merged.md` (not embedded here, by design).

## Arc

Commercial was the **fifth and last** discipline and ran the most mature version of the method: a 30-source census across four lean batches → synthesis (F01–F24) → gap audit → revision (wording/guardrail-only) → final audit → output-specificity mapping → implementation-readiness handoff → final branch handoff. The problem it solved: the existing Commercial baseline was "directionally correct but too generic", so the work pinned every Commercial claim to observable tape evidence inside the unchanged six-field model, without touching scores, weights, schema or pipeline.

## What the consolidated rubric covers

The Commercial weighting is acting-as-presence 60% / brief_adherence 20% / technical 15% / audio 5%, enforcing:

- **Commercial realism / naturalism** — grounded, believable, relatable delivery (not theatre acting, not generic screen acting, not exaggerated salesmanship), with observable behavioural anchors.
- **Tone calibration + copy handling** — tone matched to the supplied brief/product/situation; copy clarity via cue-words, rhythm, emphasis, point of view.
- **Camera relationship** — task-split between direct-to-camera (lens address) and off-camera-reader/scene style (mediated eyeline); no universal eyeline rule.
- **Product / brand / situation awareness** — only where the brief/copy/observable context supplies it; a hard no-brief invention block (no brand/buyer/audience/casting-fit).
- **Self-tape execution** as an assessability/reliability precondition (sight, sound, framing, continuity); simple capture accepted, polish/equipment never merit; audio separated from performance.
- **Special contexts** — no-dialogue/silent reaction work and voiceover-style copy as conditional; UGC/presenter/corporate carried as under-evidenced limitations. Cross-cutting guardrails: anti-marketability/appearance, live-room overclaim block.

## Deviations / findings

- **Late-stage order (corrected to content-logical).** By **content** the Commercial Output-Spec consumes the Final-Audit (it cites COMMERCIAL-FINAL-D01/D02), so the chain follows that dependency: Syn → Audit → Rev → **Final-Audit → Output-Spec** → Implementation. The filesystem timestamps (which place the Output-Spec file earlier) are unreliable and were overridden in favour of the content dependency. See [[drr-commercial-09-final-audit]] and [[drr-commercial-10-output-spec]].
- **Unique implementation-readiness step** ([[drr-commercial-11-implementation]]): NOT live wiring, code or deployment — an *implementation-readiness* pack (rule→production-requirement matrix, per-section report-behaviour requirements, exclusion/safety pack, generic-phrase replacement guide, display-verification + live-QA/regression packs, and a non-regression protection pack). It is "production-readiness planning material, not implementation."
- **B2/B3 birthtime inversion** — `C-B2` was created after `C-B3` by clock; ordered by batch number (B2 before B3). All output-spec/implementation work is **synthetic** (no live Commercial reports/PDFs/comparison pages existed); live-output QA gates release, not consolidation.

## Key lesson

For a shared-schema product, discipline maturity comes from tightening evidence standards, claim-scope and guardrail wording **inside the existing fields** — never by adding score fields, weights or pipeline changes — and the work is not "done" until those rules become an explicit, testable output-spec + implementation-readiness pack, with a live-output QA gate held open for after the wording ships.
