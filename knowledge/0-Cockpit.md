# Cockpit

## How to use this cockpit

This page is for SEEING what's going on — what's decided, what's current, and what's still open. When something needs changing — resolving a question, recording a decision, updating a status — that happens in Claude Code, not by editing notes here. The habit is simple: read here, change through Code. (Jotting a quick raw thought in Obsidian is fine — it's your notebook. It's the structured changes that go through Code.)

---

## What's still open

- **What this shows:** Anything still undecided — questions raised but not yet answered.
- **What to do:** These are waiting on you. To clear one: settle the answer (some can't be answered yet — they correctly sit here until the work behind them is done), then tell Claude Code the decision. Code writes the answer in, removes the flag, and records it as a decision; it drops off this view when you next sync. Don't answer by typing into the note here — letting Code do it keeps the answer, the flag removal, and the decision record together and reviewed.
- **Good to know:** Empty is good — nothing's waiting on you.

## Work in flight between you and Code

- **What this shows:** Work passed between a chat session and Claude Code, and the state it was left in.
- **What to do:** Check this when you start or resume work. To pick one up or close it, do that in Claude Code — not by editing here.
- **Good to know:** A handoff stays listed until its work is done and Code closes it. The group headings are the states: requested (queued, not started), in progress, done, blocked.

![[cockpit.base#Handoffs]]

## Everything, by where it stands

- **What this shows:** Every note in the vault, grouped by where it is in its life — still exploratory, currently in force, settled as a decision, or replaced.
- **What to do:** Nothing — this is for reading, the bird's-eye view of the whole corpus. If you spot something wrong or missing, that's a change to hand to Claude Code, not an edit to make here.
- **Good to know:** The group names mean: **exploratory** = an idea or research still forming (not authoritative); **current** = in force today; **decided** = settled and locked in; **superseded** = replaced by something newer.

![[cockpit.base#Status board]]

## What's been captured lately

- **What this shows:** Every note in the order it was captured, newest first — the vault's diary.
- **What to do:** Nothing — skim it after a capture session to confirm the session's notes landed, or to remind yourself what happened recently. If something looks wrong or missing, that's a change to hand to Claude Code, not an edit to make here.
- **Good to know:** This grows with every capture. If a session you remember isn't here, the capture may not have been run — ask Code to capture it.

![[cockpit.base#Capture log]]

## Research still cooking

- **What this shows:** Research threads that are open and still forming — looked into, but not yet settled into something current or decided.
- **What to do:** Mostly just read — this is the "being looked into" pile. If a thread here is actually finished, or events have answered it, tell Claude Code and it will settle the note properly (upgrade it, or mark it superseded). Don't edit it into shape here.
- **Good to know:** Grouped by confidence — how sure the research is so far. Nothing in this view is authoritative yet; that's what makes it the queue.

![[cockpit.base#Research queue]]

## What's been replaced

- **What this shows:** Old knowledge that newer knowledge has replaced — kept as history, with what replaced it and why.
- **What to do:** Nothing — this is the archive trail. It's useful when you wonder "didn't we decide this differently before?" — the answer and the why are here. If you spot something wrong or missing, that's a change to hand to Claude Code, not an edit to make here.
- **Good to know:** Nothing in this view is in force. Notes arrive here automatically when Code records a replacement — nothing is ever just deleted.
