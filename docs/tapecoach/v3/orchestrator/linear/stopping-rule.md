# Stopping Rule

One PR closes one linear task.

Fix P0/P1 before merge.

Defer P2 unless it blocks the defined task.

Do not expand task scope during review.

Do not add gates, scripts or validators because review identifies future hardening. Record future hardening in the deferred gates backlog or next task recommendation instead.

Do not use Codex completion, GitHub checks, Lovable publish or Storage-download review as release approval by themselves.
