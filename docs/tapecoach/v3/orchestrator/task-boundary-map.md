# Task Boundary Map

- Setup Tasks 1–4 are orchestrator/automation setup tasks.
- Sprint 0 / R0–R4 contract package is a later product-delivery package executed by the orchestrator after setup acceptance.
- Do not confuse setup with product release implementation.
- Setup Task 1 may include minimal contract/gate scaffolding, not full Sprint 0 unless explicitly scoped.
- Setup Task 2 = ChatGPT ↔ Codex orchestrator.
- Setup Task 3 = Lovable publish lane.
- Setup Task 4 = local Storage-download QA lane.
- Product release R0–R16 begins only after setup design acceptance and setup completion/explicit sequencing approval.
